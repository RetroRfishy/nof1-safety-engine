# PMData subset (unmodified)

Only the files the apps read: `fitbit/resting_heart_rate.json`, `fitbit/sleep.json` and
`googledocs/reporting.csv` for participants p01–p16. Files are copied unmodified.

Source: PMData, Simula Research Laboratory — https://datasets.simula.no/pmdata/ and https://osf.io/vx4bk/

Citation: Thambawita V., Hicks S. A., Borgli H., et al. *PMData: A Sports Logging Dataset.*
11th ACM Multimedia Systems Conference (MMSys '20), 2020. https://doi.org/10.1145/3339825.3394926
